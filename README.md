# MARTINALEXEI · sitio web

Sitio estático (HTML + CSS + JS). Todo lo que cambia por cliente está en `config.js`:
nombre, contacto, WhatsApp (sin número, el botón se oculta), horarios, tratamientos, reels y rutas de fotos/videos.

- Videos y fotos: carpeta `assets/`.
- Para agregar un reel: copia el `.mp4` a `assets/videos/` y añade una línea en `reels` de `config.js`.
